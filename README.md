# 스윙자로

혼자 쓰는 골프 스윙 연습 노트. 휴대폰으로 찍은 스윙 영상에서 플레인을 재고,
치고 싶은 구질에 맞춰 셋업을 잡고, 집중 교정 문제 하나를 정해 회차별로 추적한다.

주소: https://minimalbreeze.github.io/swingjaro/

## 이 앱이 하는 일과 하지 않는 일

**하는 일** — 영상에서 관절을 자동으로 찾아 각도와 비율을 계산한다(휴대폰 한 대로
재는 2D 추정). 그 값을 코칭에서 흔히 쓰는 범위와 비교해 벗어난 구간을 알려준다.
같은 자로 매번 재기 때문에 회차 간 변화는 믿을 만하다.

**자동으로 못 하는 것** — 클럽헤드와 볼은 사람 관절이 아니라 포즈 모델이 못 본다.
볼은 클럽 라이각과 손·지면 위치로 추정하고, 화면에서 눌러 고칠 수 있다.
클럽헤드가 있어야 하는 항목(톱 클럽 위치, 임팩트 샤프트 기울기)은 자동 분석에서
빼고 잰다. 필요하면 "구간"에서 직접 찍으면 그 항목까지 나온다.

**하지 않는 일** — 볼을 보지 않는다. 그래서 "이렇게 고치면 더 멀리·똑바로 간다"를
이 앱이 검증한 것이 아니다. 솔루션과 장비 제안은 일반 통념이고, 실제 스윙
데이터로 학습하거나 결과로 검증한 값이 아니다. AI 모델도 아니다(선택 기능인
자동 관절 인식만 예외).

그래서 결과 기록 기능이 있다. 진단이 나에게 실제로 맞는지는 앱이 아니라 내
기록이 답한다.

## 쓰는 순서

1. **설정** — 클럽, 촬영 각도(측면/정면), 치고 싶은 구질을 고른다.
   손잡이·민감도·내 클럽 거리는 "세부 설정"에 접혀 있다.
2. **영상** — 파일을 고른다. 기기 안에서만 재생되고 어디에도 올라가지 않는다.
3. **자동 분석** — 여기서부터는 사람이 할 일이 없다. 영상을 훑으며 프레임마다
   관절을 찾고, 손의 높이와 속도 흐름으로 어드레스 · 테이크백 · 톱 · 다운스윙 ·
   임팩트 · 피니시를 스스로 집는다. 끝나면 진단 화면으로 바로 넘어간다.
   결과가 이상하면 "구간"에서 점을 끌어 고치면 다시 계산된다.
4. **진단** — 영상 위에 정상 플레인과 내 스윙이 겹쳐 그려진다. 벗어난 구간마다
   원인·교정 방향·드릴·참고 영상이 붙는다. 목표 구질을 막는 항목이 있으면
   맨 위에 먼저 알려준다. 문제 하나를 "집중 교정"으로 정한다.
5. **장비** — 구질·탄도·컨택·캐리를 넣으면 로프트·라이각·샤프트 등을 제안한다.
6. **🎯 구질** — 내 구질에 맞는 그립(너클 개수까지)·볼 위치·스탠스·조준 가이드.
   최근 분석과 대조해 지금 궤도가 그 구질과 맞는지도 알려준다.
7. **💬 문의** — 안 되는 걸 찾으면 원인·점검·교정을 알려준다. 최근 분석에서
   그 원인이 실제로 잡혔는지까지 대조한다.
8. **📊 기록** — 그날 실제 결과를 남긴다. 회차가 쌓이면 점수와 실제 결과가 같이
   움직이는지 산점도로 보여준다.

## 바탕화면 바로가기

설정 화면 아래 **"📲 바탕화면에 바로가기 만들기"** 카드에서 추가한다.
안드로이드 크롬과 PC 크롬·엣지는 버튼 한 번이면 되고, 아이폰 사파리는
공유 버튼 → "홈 화면에 추가"로 직접 해야 한다(카드에 안내가 있다).

## 촬영

- **측면(다운더라인)**: 볼과 타깃을 잇는 선의 연장선 뒤, 손 높이, 3~4m
- **정면(페이스온)**: 골퍼 정면, 벨트~가슴 높이, 3~4m
- 세로 촬영, 60fps 이상, 삼각대 고정. 스윙 시작 1초 전부터 피니시 1초 후까지.

카메라 높이와 각도가 달라지면 측정값도 달라진다. 회차를 비교하려면 촬영 조건을
매번 같게 맞추는 것이 가장 중요하다.

## 기록 백업

기록은 이 브라우저의 `localStorage`(`swingjaro:` 접두사)에만 있다. 폰을 바꾸거나
사이트 데이터를 지우면 사라지므로, 기록 화면에서 가끔 파일로 내보내 둘 것.

## 배포

빌드 도구 없는 정적 사이트다. GitHub Pages 설정에서
**Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)`** 로 두면 끝.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 뼈대 |
| `swing.css` | 스타일 |
| `swing-data.js` | 클럽·촬영각도·구간·구질 기준값 |
| `swing-faults.js` | 문제 사전(증상·원인·교정·드릴·영상) |
| `swing-shot.js` | 목표 구질 가이드 + 증상 문의 사전 |
| `swing-analyze.js` | 기하 계산, 진단 판정, 장비 피팅 |
| `swing-log.js` | 결과 기록과 대조(산점도·상관) |
| `swing-pose.js` | 관절 인식 모델 로더(누를 때만 내려받음) |
| `swing-auto.js` | 자동 분석 — 영상 훑기, 스윙 구간 찾기, 좌표 변환 |
| `swing-install.js` | 바탕화면 바로가기(PWA 설치) |
| `swing.js` | 화면 로직 |
| `manifest.json` | 앱 정보·아이콘 |
